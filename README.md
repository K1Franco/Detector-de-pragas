# Agro Essencial - Diagnóstico de Pragas

Este é um aplicativo que usa Inteligência Artificial para diagnosticar pragas nas plantas com base em imagens. 

## Como usar:
1. Carregue uma foto da planta afetada.
2. O sistema retornará a praga identificada e a confiança da predição.

## Requisitos:
- Python 3.7+
- TensorFlow
- Streamlit

Para rodar localmente, basta rodar o comando:
```
streamlit run app_pragas.py
```
